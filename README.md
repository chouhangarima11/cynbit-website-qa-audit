
# Cynbit Technologies – Website QA Audit

## Project Overview
This repository contains a preliminary Quality Assurance (QA) audit of the Cynbit Technologies website.

**Website:** https://www.cynbit.in/

**Assessment:** QA Testing Intern – Website Quality Audit

## Objectives
- Review website navigation.
- Identify possible functional issues.
- Document testing observations.
- Suggest improvements to website usability.
- Maintain a structured bug register and test cases.

## Documents Included
1. `QA-Audit-Report.docx` – Editable QA audit report.
2. `QA-Audit-Report.pdf` – PDF version of the audit report.
3. `Bug-Test-Issue-Register.xlsx` – Excel workbook containing:
   - Bug Register
   - Test Cases
   - Recommendations
4. `Screenshots/` – Actual screenshots captured during testing.

## Preliminary Findings
- BUG-001: Careers navigation – no visible response reported after tapping.
- BUG-002: Case Studies navigation – no visible response reported after tapping.

Both observations require further reproduction and verification.

## Testing Method
Manual website testing using an Android mobile device.

## Limitations
This is a preliminary audit. Tests that have not been performed are marked as Not Run. Device model, browser version, screen resolution and other missing environment details should be added when available.

## Conclusion
The audit records initial navigation observations and provides recommendations for further functional, usability, responsiveness and compatibility testing.
